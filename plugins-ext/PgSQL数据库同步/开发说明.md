Copyright (C) 2025 屈想顺. Licensed under AGPL-3.0.

## 功能

在 **Electron 桌面版**中调用本机 **`pg_dump` / `pg_restore` / `psql`**，对 PostgreSQL 做 **`-Fc` 自定义格式**导出与 **`--clean --if-exists`** 恢复；与「数据库同步」插件的逐表 INSERT 不同，适用于 **NetBox** 等需完整逻辑备份的场景。

主进程脚本：**`pg-sync-main.js`**（`invoke-plugin-main`），依赖 **`pg`** 做版本探测。

## 文件

| 文件 | 说明 |
|------|------|
| `manifest.json` | `id`: `pgsql-sync` |
| `App.vue` | 界面：连接信息、bin 目录、导出/导入/版本检测等 |
| `pg-sync-main.js` | `testVersions` / `exportDump` / `importDump` / `cleanDump` / `verifyMigrations` |
| `package.json` | `dependencies`: `pg` |

## 构建

```bash
npm run build:plugins -- PgSQL数据库同步
```
